# fetchpics — Photo/Video Management Toolkit

A collection of Python utilities for organizing, deduplicating, and managing photo and video files.

## Scripts

### `fetchpics.py`
**Photo/video import tool with duplicate detection**

Imports photos and videos from a source directory to a destination, detecting and skipping duplicates using file hashing.

**Usage:**
```bash
./fetchpics.py init <dir>              # Initialize DB with contents of dir
./fetchpics.py fetch <src> <dst>       # Copy non-duplicate files from src to dst
./fetchpics.py fetch --preserve-dirs <src> <dst>  # Copy while preserving directory structure
```

### `fetchpics2.py`
**Enhanced photo/video consolidation with lazy-hash duplicate detection**

An improved version with size-first duplicate detection that defers expensive hash calculations until needed. Safe for large collections.

**Key features:**
- Fast reindexing (only stat()s files, no hashing)
- Lazy hashing (only computes hashes when size collisions occur)
- Deletion-safe (requires confirmed hash match before deleting source files)

**Usage:**
```bash
./fetchpics2.py --db DB reindex <dir>               # Record contents of dir (no hashing)
./fetchpics2.py --db DB fetch <src> <dst>           # Copy non-duplicate files src -> dst
./fetchpics2.py --db DB fetch --preserve-dirs ...   # Preserve source dir structure
./fetchpics2.py --db DB fetch --delete ...          # Delete source files after verified import
```

### `organize_by_date.py`
**Organize photos/videos into YYYY/MM/ directory structure**

Reads EXIF metadata, filenames, and paths to determine capture dates, then organizes files into a date-based folder hierarchy.

**Date detection (priority order):**
1. EXIF DateTimeOriginal or DateTime
2. Filename patterns (YYYYMMDD, YYYY-MM-DD, etc.)
3. Path patterns (YYYY/MM or YYYY-MM in directory names)
4. File modification time (fallback)

**Usage:**
```bash
./organize_by_date.py scan <src> <dst>              # Show detected dates for all files
./organize_by_date.py organize <src> <dst>          # Move files to YYYY/MM/ structure in dst
./organize_by_date.py organize --copy <src> <dst>   # Copy files instead of moving
```

### `exif_fixer.py`
**Fix EXIF data: add photographer based on camera, add date from path/filename**

Reads and updates EXIF metadata. Maps camera hardware to photographers and can set DateTimeOriginal from filenames and paths.

**Usage:**
```bash
./exif_fixer.py set-photographer <src_dir>  # Set photographer for all files based on camera
./exif_fixer.py set-dates <src_dir>         # Set DateTimeOriginal from filename/path/other tags
./exif_fixer.py report <src_dir>            # Show assignments preview
```

### `exif_map.py`
**Identify camera hardware and map to photographers**

Analyzes EXIF data to identify what cameras are present in a collection and which photographers own them.

**Usage:**
```bash
./exif_map.py <directory>  # Scan directory and report camera usage
```

### `lint_pics.py`
**Validate photo/video collection for quality issues**

Scans a directory for common media issues like:
- Missing or corrupted EXIF data
- Duplicate files
- Unusual resolutions or aspect ratios
- Other media quality problems

Generates a CSV report with flagged files for review.

**Usage:**
```bash
./lint_pics.py <src_dir> [--output lint_report.csv]  # Scan and generate report
```

### `review_lint.py`
**Interactive review tool for lint_pics reports**

Processes the CSV report generated by `lint_pics.py`, allowing interactive review of flagged files with options to delete or keep them.

**Usage:**
```bash
./review_lint.py <lint_report.csv> <collection_root>  # Interactive review of flagged files
./review_lint.py <lint_report.csv> <collection_root> --auto-delete  # Auto-delete all flagged files
```

## Typical Workflow

1. **Collect files** from various sources using `fetchpics.py` or `fetchpics2.py`
2. **Organize by date** using `organize_by_date.py` to create YYYY/MM/ structure
3. **Fix metadata** using `exif_fixer.py` to set photographer and date information
4. **Validate collection** using `lint_pics.py` to find issues
5. **Review and clean** using `review_lint.py` to interactively fix or delete flagged files
